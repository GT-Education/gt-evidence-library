# Is Financial Aid or a Scholarship Available for GT Anywhere?

GT Anywhere is priced at a single tuition tier, deliberately set below the level of several state
education savings account awards so that ESA funding can cover it for eligible families. For families in
states with an ESA, that funding is the primary affordability route, and it is covered separately in the
guide on using state ESA funds.

The question below is about help for families who are not ESA-eligible, or whose award does not cover
the full amount.
